# EMSO ERIC Example Dataset ERDDAP #

This repository hosts the configuration of the [NetCDF-dev ERDDAP](https://netcdf-dev.obsea.es/erddap/index.html) 
deployment with examples of  [EMSO-Compliant](https://github.com/emso-eric/emso-metadata-specifications/tree/develop) datasets. The datasets are generated with the `test_metadata_harmonizer.py` script from the [Metadata Harmonizer](https://github.com/emso-eric/metadata-harmonizer/tree/develop) toolkit.
